ManimAgent Setup Guide
======================

1. Install prerequisites
   - Python 3.10+; Python 3.11 is recommended.
   - FFmpeg on PATH.
   - Manim system dependencies.
   - LaTeX/MiKTeX for Tex and MathTex scenes.
   - OpenAI API key.

2. Create a virtual environment
   Windows PowerShell:
       python -m venv .venv
       .\.venv\Scripts\Activate.ps1

   macOS/Linux:
       python3 -m venv .venv
       source .venv/bin/activate

3. Install Python dependencies
       pip install -r requirements.txt

   macOS users can additionally install:
       pip install -r requirements-macos.txt

   Optional voiceover compiler mode:
       pip install -r requirements-voiceover.txt

4. Add your API key
   Create .env in this folder:
       OPENAI_API_KEY=sk-proj-your-key

   If .env is missing, main.py will ask for the key and save it.

5. Run the project
       python main.py

6. Outputs
   Each run creates:
       projects/<concept>/debug
       projects/<concept>/output
       projects/<concept>/media
       projects/<concept>/final

   The debug folder includes storyboard JSON, scene DSL, diagnostics,
   quality report, and assembly result files.

   The merged video is saved in the final folder when rendering succeeds.

7. Optional manim-voiceover mode
   Windows PowerShell:
       $env:MANIMAGENT_VOICEOVER_MODE="manim_voiceover"
       python main.py

   Default mode is audio_mixin.
